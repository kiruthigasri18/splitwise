<h1>Expense Splitter </h1>

<h3> Goal</h3>
<p>To build a smart, automated expense management system that dynamically recalculates each member’s share, ensures transparent reimbursements and tracks every wallet transaction like real-time digital payments.</p>

<h3> Objective</h3>
<p>
The objective of the project is to 
<ul>
  <li> Dynamically splits expenses among group members</li>
  <li></li> Automatically readjusts balances when new members or expenses are added</li>
  <li> Supports reimbursement for overpaid members</li>
  <li>Provides a wallet system to manage deposits, withdrawals, and check balances</li>
  <li>Displays detailed transaction history similar to GPay or UPI apps</li>
</ul>
</p>


<h3> Wallet System</h3>
<ul>
  <li>Users can deposit or withdraw money within the app wallet.</li>
  <li>Each transaction is logged for transparency.</li>
  <li>Wallet shows balance summary and complete transaction history.</li>
  <li>Supports balance check, transfer, and reimbursement adjustments.</li>
</ul>
